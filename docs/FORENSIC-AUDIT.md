# FORENSIC-AUDIT.md

Evidence-based production gap report. Every classification below was derived by
reading the source, the Prisma schema, the migrations, the route handlers, the
worker, the tests, the CI workflow and the deployment files in this repository —
not from prior audit docs or roadmap claims. Where a feature is only documented
(in `.env.example`, `CLAUDE.md`, `docs/*`) but has no implementing code, it is
recorded as **MISSING** regardless of what the docs say.

## Method

- **Static inspection**: full `schema.prisma` (51 models), all 12 tracked
  migrations, all 13 API route handlers, all 11 Server Action files, the worker
  entrypoint + 7 processors, `packages/services/src` (≈230 files), the AI layer,
  the auth/RBAC/security/observability modules, `next.config.mjs`,
  `instrumentation.ts`, `middleware.ts`, both Dockerfiles, `docker-compose.production.yml`,
  `deploy/`, `scripts/check-env.mjs`, `.github/workflows/ci.yml`.
- **Grep sweeps** for `TODO|FIXME|HACK|STUB|mock|placeholder`, for each external
  dependency (`@aws-sdk`, `@sentry`, `@opentelemetry`, `resend`, `searchconsole`,
  `Notification`), for `eval|child_process|dangerouslySetInnerHTML`, for auth
  guards on every route/action, and for `process.env` usage.
- **Executed this session**: `pnpm lint` (0 warnings, 14/14), `pnpm typecheck`
  (0 errors, 14/14), `pnpm test` / `vitest` — **`packages/services` 506 tests /
  83 files pass**, `scripts/check-env.test.mjs` 9/9 pass; `apps/web` and
  `apps/worker` report **"No test files found"**.
- **Not re-executed** (CI-gated, no Docker/Postgres in this environment):
  Playwright e2e (58 pass in CI), the `*.integration.test.ts` suites (pass in CI
  against Postgres 16), any `docker build`, any Next standalone build.

## Verdict

**Not production-ready. Ship-blocking gaps exist that are not visible from a
green `lint`/`typecheck`/`test` run.** The application core is genuine and
well-built — real API clients, a real SSRF-safe crawler, real Stripe/OAuth
adapters, 500+ real unit tests over the business logic, disciplined additive
migrations, and a single RBAC choke point. But: the container images have never
been built or run; email sign-in does not function with the default
configuration; there is no boot-time environment validation (the file meant to
do it is dead code); and four subsystems the documentation presents as part of
the stack — **object storage, Sentry, OpenTelemetry, and the notification
system** — have **zero implementing code**.
